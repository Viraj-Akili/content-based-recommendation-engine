# Content-Based Recommendation Engine

## Overview
A recommendation system that suggests technology career paths based on user skills using TF-IDF vectorization and cosine similarity.

## Features

- TF-IDF weighting
- Cosine similarity matching
- Skill autocomplete
- Dynamic ranking
- Match percentage visualization
- Interactive dashboard
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Recommendation Pipeline

1. User enters skills
2. Skills are transformed into a TF-IDF vector
3. Job roles are transformed into TF-IDF vectors
4. Cosine similarity scores are calculated
5. Top matches are ranked and displayed
