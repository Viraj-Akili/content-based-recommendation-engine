Scientific Methodology & System Architecture

Information Retrieval Principles

1. TF-IDF Vectorization

Transforms user skills into high-dimensional sparse vectors where weights reflect term frequency balanced by Inverse Document Frequency ln(N / (1 + DF)) to penalize overly common terms.

2. Cosine Similarity

Measures the cosine angle (u · r) / (||u|| * ||r||) between the user query vector and candidate role profiles, providing an orientation-based similarity metric in range [0.0, 1.0].

3. Hybrid Scoring & Explainability

Combines 65% cosine proximity with 35% Weighted Skill Coverage to prioritize essential core requirements and identify high-priority missing skills to learn.
